# dxfcheck — AutoCAD DXF 도면 검증기 (KEC 기준)

AutoCAD 자동화 설계로 생성한 DXF 도면(또는 도면 묶음 ZIP)을 넣으면 **파일·구조, CAD 품질, 도면 표기, KEC(한국전기설비규정) 전기 규정, 도면 세트 정합성(E-01~E-21), 학습 기준 비교**로 검사하고 한국어 보고서(Markdown/JSON)를 냅니다.

```bash
uv venv .venv && uv pip install --python .venv/bin/python -e ".[dev]"
.venv/bin/dxfcheck 도면.zip                       # 표준출력으로 Markdown
.venv/bin/dxfcheck 도면.zip -f both -o reports/r1  # reports/r1.md + r1.json
.venv/bin/dxfcheck a.dxf 폴더/ --config my.json --fail-on error   # CI용 종료코드

# 학습: 승인된 기준 도면 세트로 프로파일 생성(여러 번 실행하면 누적)
.venv/bin/dxfcheck learn 승인본1.zip 승인본2.zip --profile profiles/pv.json
.venv/bin/dxfcheck 신규도면.zip --profile profiles/pv.json -f both -o reports/r2
```

## 도면 세트 정합성 (E-01~E-21)
도면번호를 **파일명 → 표제란 도면번호 속성 → 도면 문자** 순으로 인식하고 'AutoCAD 자동화 설계' 6장 항목을 검사합니다.
기준값은 **XRECORD 설계 메타데이터**(JSON, 문자열 태그 또는 이진 310 태그 · zlib 압축 지원), 없으면 **도면 간 다수값**입니다.

| 규칙 | 검사 |
|---|---|
| SET-001 / SET-E01-1 | 도면번호 중복, E-01 목록표 ↔ 실제 파일 1:1(누락·미등재·도면명), 목록표 없으면 정본 목록 대비 누락 |
| SET-002 | 도면번호와 내용 불일치(정본 키워드) |
| SET-E01-2 | 모든 표제란 회사명(`company_name`, 기본 에이치에너지) |
| SET-E01-3 | 설비용량 E-01·02·03·04·09 일치, **설계 용량 = 모듈 수 × 모듈 출력**(목표 용량 p_pv_kw 기입 의심 안내) |
| SET-E02-1 / E04-2 | 모듈 수·인버터 수·모듈 출력·인버터 용량 도면 간 일치 |
| SET-E04-1 / E02-2 | 직렬·병렬 수 E-04·08·09·10 일치, 직병렬 × 인버터 = 모듈 수 |
| SET-E02-3 | 최대 스트링 전압 ≤ 인버터 최대 입력전압, ≤ DC 1,500V(KEC 111.1 저압) |
| SET-E04-3 / E10-1 / E21-1 | DC 퓨즈 E-04·09·10 일치, MPPT 수 E-10·13·21, E-21 채널 수 |
| SET-E05-1 | 간선 규격 = 계산서(메타데이터) 또는 E-04, 하드코딩 의심값(`hardcode_suspects`) |
| SET-E11-1 / E11-2 | E-11 페이지 수 = 인버터 수, DC 단면적 = 계산서 · ≥ `dc_cable_min_sq` |
| SET-E03-1 / E15-1 | 수전 방식 일치, 저압 수전 ↔ E-15 포함 여부 |
| SET-E19-1 / E17-1 / E16-1 | 설치 형태·트레이 유형 일치, 지상형 ↔ E-16, 기초 표기 |
| SET-E12-1 / E13-1 / E14-1 | 모듈 치수 = 메타데이터, 모듈·인버터 모델 표기, 외형 스킵 옵션 |
| SET-Exx-P | 도면별 필수 표기(WHM, PEN/PE/본딩, 클램프, 극성, 간격, 두께·볼트, MPPT 매핑 …) |
| SET-P91 / E03-2 / E04-4 / E04-5 | `mm²` 사용, 블록 비균일 축척(스케일 왜곡), 비표준 레이어(`standard_layers`), A3 영역 초과 |

## 학습 기준 비교 (PRF-*)
`dxfcheck learn`은 승인된 기준 도면에서 **도면번호별 통계 프로파일**을 만듭니다(신경망 학습이 아니라 근거를 그대로 읽을 수 있는 빈도 통계).
레이어 · 글꼴 · 블록 · 표제란 속성 · 표준 문구 · 설계 수치 항목 · 객체/문자 수 범위 · 세트 구성을 누적하고, 검증 시 다음을 지적합니다.

| 규칙 | 내용 |
|---|---|
| PRF-001 | 학습한 어떤 기준에도 없던 레이어 (비표준 레이어) |
| PRF-002 / 003 / 004 | 기준 80% 이상에 있던 레이어·글꼴·표제란 속성·블록의 누락, 처음 보는 글꼴 |
| PRF-005 / 006 | 표준 문구 누락, 늘 읽히던 설계 수치 항목 누락 |
| PRF-007 | 객체·문자 수가 기준 범위를 크게 벗어남(누락·중복 생성 의심) |
| PRF-010 | 기준 세트에 늘 있던 도면번호 누락 |

기준 샘플이 3개 미만이면 '참고', 3개 이상이면 '주의'로 표시합니다.

## 인식하는 전기 표기
- 전선: `F-CV 4C 25㎟`, `0.6/1kV F-CV 4C-25SQ`, `CV 1C 95SQ×4`, `2(CV 1C 240SQ×4)`, `HFIX 2.5㎟ X 3`, `TFR-CV`, `HFCO`, `CVV` …
- 보호·접지도체: `+E 16㎟`, `F-GV 6㎟`, `접지선 GV 16SQ`, `피뢰 접지도체 …`
- 차단기: `MCCB 3P 100AF 75AT 25kA`, `ELB 2P 30AF 20AT 30mA`, `MCB 1P 20A`, `누전차단기 …`, `FUSE 50A`, `50AF/40AT`
- 태양광: `550Wp × 180장`, `15직렬 X 6병렬`, `인버터 50kW × 2대`, `DC FUSE 15A`, `MPPT 수: 3`, `MPPT1: 2스트링`, `H1Z2Z2-K 1C 6㎟`, `최대 스트링 전압 742V`
- 부가정보: `L=45m`, `IB=32A`, `15kW`, `380/220V`, `3Φ4W`, 용도(조명·콘센트·욕실·옥외·동력·제어·피뢰)

TEXT·MTEXT·블록 속성(ATTRIB)·블록 안 문자(중첩 포함)를 모두 읽습니다. 차단기와 전선은 **같은 문자 → 같은 행(표) → 근접** 순으로 연관하고, 근접 추정은 '주의'로 낮춥니다.

## 설정 (`--config my.json`)
```json
{ "cable_method": "C", "wire_method": "B1", "derating": 0.8, "supply_type": "B", "power_factor": 0.9 }
```
`config.py`의 `Settings` 필드를 그대로 씁니다. 규정 수치는 `kec.py`에 모여 있어 개정 시 그 파일만 고칩니다.

## 판정
- 🔴 부적합: 규정 위반 또는 도면을 쓸 수 없는 결함 (점수 −15)
- 🟡 주의: 위반 가능성·확인 필요 (−4)
- 🔵 참고: 권고·검토 한계
- 파일 판정: 부적합 있음 → 부적합 / 주의만 → 조건부 적합 / 없음 → 적합 / 읽기 실패·DWG → 검증 불가

## 한계
도면의 **문자 표기**를 근거로 판정합니다. 선만 그려진 결선, 표기 오기, 현장 조건(주위온도·집합·포설 방법)은 설정값 이상으로 알 수 없습니다. 보고서는 설계 검토 보조 자료이며 최종 판단은 전기 설계·감리 기술자가 합니다.
